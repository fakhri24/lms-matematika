# Learning Management Siswa - Matematika Project

## Business Requirements

- Web aplikasi JavaScript Vanilla dengan MVP.
- Refactor sehingga alur logika aplikasi tidak berubah tapi kode lebih mudah dibaca dan dimanage.

## Technical Details

- Use JavaScript Vanilla.
- Use popular libraries.
- As simple as possible but with an elegant UI.

## Color Scheme

- Elegant color that spark the viewer.

## Strategy

1. Write plan with success criteria for each phase to be checked off. Include project scaffolding, including .gitignore, and rigorous unit testing.
2. Execute the plan ensuring all critiera are met.
3. Cari bug yang mungkin muncul dan selesaikan, buktikan masalah bug, lalu perbaiki kode, tes dan buktikan hasil perbaikan kode.
4. Only complete when the MVP is finished and tested, with the server running and ready for the user.

## Coding standards

1. Use latest versions of libraries and idiomatic approaches as of today.
2. Keep it simple - NEVER over-engineer, ALWAYS simplify, NO unnecessary defensive programming. No extra features - focus on simplicity.
3. Be concise. Keep README minimal.
